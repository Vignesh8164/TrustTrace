# ADR-001: TypeScript Express and SQLite for the local MVP

## Status

Accepted

## Decision

Use a single TypeScript Node.js service with Express, `better-sqlite3`, and a React/Vite frontend. Keep the API, deterministic policy engine, audit persistence, and UI in one repository and one deployable container.

## Context

The buildathon requires a working, reproducible local demonstration with persisted decisions, tests, and a polished interface. A distributed architecture would add operational and security complexity without improving the core demonstration.

## Consequences

This provides fast startup, offline-friendly tests, typed boundaries, and a small attack surface. It is not a production multi-tenant architecture: SQLite is local, authentication is intentionally absent, and audit integrity is application-level rather than cryptographic. Those limitations are documented rather than hidden.
